# GPT Image 2 regeneration batch: the 8 rejected images

Companion to `docs/GPT_IMAGE_2_MASTER_PROMPT.md` and `docs/IMAGE_MANIFEST.md`.
These 8 prompts replace only the rejected numbers from the first batch
(02, 08, 17, 25, 26, 29, 31, 32); the other 27 are already installed and
should not be regenerated. Each prompt below is fully self-contained, so it
can be submitted on its own, in any order, or all 8 together in one request.

**Root cause of 5 of the 8 rejections.** GPT Image 2 kept rendering a
garment's neck label, a care label, or a chest emblem as crisp, legible,
fabricated brand text or a logo, even though the first master prompt already
said "no readable label text." Implying it was not enough; every prompt
below states it as an explicit, first-line rule instead. The other 3
rejections (a signage plaque, a repeated logo, gibberish stitched text) get
their own targeted fix in addition to that shared rule.

Install path for each approved result is unchanged from the original
manifest: save at the **Repository destination** below, then follow
`docs/IMAGE_MANIFEST.md` section 2.

---

## Shared rule, repeated at the top of every prompt below

Absolutely no readable text, wordmark, monogram, crest, emblem, logo, or
brand mark anywhere in the frame, on any garment, label, tag, carton,
signage, wall, or surface, even a stylised, illegible-looking, or partially
obscured one. Where a garment shows a neck label or care label, render it
completely blank, or turn it fully away from camera / fold it under so no
label surface is visible at all. This rule overrides any instinct to add
authenticity through logos or labels; authenticity comes from the
photography, not from invented branding.
